# Contributing

Thanks for considering a contribution. Please:

1. Open an issue first to discuss the change.
2. Use conventional commit messages (`feat:`, `fix:`, `docs:`, `ci:`).
3. Run `pnpm -r typecheck` and `pnpm -r test` before opening a pull request.
4. Keep pull requests small, focused, and described.
